# Sri Krishnadevaraya — Tribute Page

A visually engaging tribute page dedicated to **Sri Krishnadevaraya**, one of the prominent rulers of the Vijayanagara Empire.

This project was developed as part of the **Oasis Infobyte Web Development and Designing Internship – Level 2 Task 2**.

## 📌 Project Overview

The webpage presents the historical and cultural legacy of Sri Krishnadevaraya through a modern, responsive design.

The page includes information about his reign, important events, literature, culture, and the lasting heritage of the Vijayanagara Empire.

## ✨ Features

- Hero section featuring Sri Krishnadevaraya
- Historical introduction
- Timeline of important events
- Culture and literature section
- Information about *Amuktamalyada*
- Distinctive quote section
- Legacy section
- Real historical images sourced from Wikimedia Commons
- Responsive layout for different screen sizes
- Clean typography using serif and sans-serif fonts
- CSS Grid and Flexbox based layouts
- Smooth visual section transitions and modern styling

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Web Design
