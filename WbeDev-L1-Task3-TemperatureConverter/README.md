## Project Description

## Conversion Formulas

### Celsius to Fahrenheit

°F = (°C × 9/5) + 32

### Fahrenheit to Celsius

°C = (°F - 32) × 5/9

### Celsius to Kelvin

K = °C + 273.15

### Kelvin to Celsius

°C = K - 273.15
