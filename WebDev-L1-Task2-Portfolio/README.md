# Personal Portfolio Website

## Oasis Infobyte Web Development and Designing Internship

### Task
Web Development and Designing - Level 1 - Task 2: Personal Portfolio

## Project Description

This project is a responsive personal portfolio website created to showcase my profile, skills, projects, education, experience, and contact information.

The portfolio was developed as part of the Oasis Infobyte Web Development and Designing Internship.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- CSS Flexbox
- CSS Grid

## Features

- Responsive navigation bar
- Hero section with professional profile
- Professional photo
- About Me section
- Skills and technical toolkit
- Project showcase
- Education and experience timeline
- Contact section
- LinkedIn and GitHub links
- Resume download
- Smooth scrolling navigation
- Responsive design for desktop and mobile devices
- Scroll-based animations
- Mobile navigation menu
