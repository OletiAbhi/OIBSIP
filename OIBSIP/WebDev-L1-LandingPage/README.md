# Google Ecosystem Landing Page

## Oasis Infobyte Web Development and Designing Internship

### Task
Web Development and Designing - Level 1 - Task 1: Landing Page

## Project Description
This project is a responsive landing page showcasing the Google ecosystem of products and services.

The website presents different Google products, services, and platforms through a clean and modern user interface. The project was created as part of the Oasis Infobyte Web Development and Designing Internship.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Web Design

## Features
- Sticky navigation bar
- Responsive hero section
- Google ecosystem overview
- Products showcase
- Services section
- About section
- Call-to-action section
- Footer with contact and social links
- Responsive layout for desktop and mobile devices
- Hover effects and visual transitions
